The command pages explain workflows and common decisions. For the exact options in the version you installed, run:

```sh
acorn help
acorn <command> --help
```

The repository's generated option reference is rebuilt from the same Clap definitions as the binary. Documentation checks keep its top-level command list aligned with the curated pages.
