# Researcher trail

Goal: describe a project once, improve it safely, and create outputs for people and machines.

<div class="acorn-growth emoji-growth five-stages" aria-label="Researcher trail from seed to tree"><span>Discover</span><span>Quest</span><span>Check</span><span>Connect</span><span>Export</span></div>

1. Read [why ACORN treats projects as first-class research objects](../motivation.md).
2. Complete the [Quick Quest](quick-quest.md) with a small research activity record.
3. Learn what [`check`](../cli-reference/commands/check.md) evaluates and how to run it offline.
4. Follow the [persistent identifier lifecycle](../concepts/persistent-identifiers.md) to find and enrich project connections.
5. Choose an [`export`](../cli-reference/commands/export.md) target such as CFF, PDF, Markdown, or PowerPoint.

Your finish line is a version-controlled RAD file that passes the checks you selected and produces at least one shareable artifact.
