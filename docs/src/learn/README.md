# Choose your path

ACORN spans research writing, communication, project coordination, data tooling, and platform operations. Pick a trail now; switch trails whenever your work changes.

| Trail | First win |
|---|---|
| [Researcher](researcher.md) | Turn one project record into checked, reusable artifacts |
| [Communicator](communicator.md) | Turn a project story into a reviewed fact sheet or presentation |
| [Project manager](project-manager.md) | Turn reviewed project updates into a status report |
| [Developer](developer.md) | Use ACORN's schemas and libraries in an application |
| [Platform engineer](platform-engineer.md) | Run repeatable ACORN workflows across a team |

If you want to see ACORN work before choosing, take the 10-minute [Quick Quest](quick-quest.md).
