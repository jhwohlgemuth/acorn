# Artifact logo sources

The SVG files in this directory are vendored from the [SVG Logos collection](https://github.com/gilbarbara/logos), formerly published at SVG Porn and now available at [SVG Logos](https://svglogos.dev/):

- `adobe.svg` from `logos/adobe-icon.svg`
- `microsoft.svg` from `logos/microsoft-icon.svg`
- `json.svg` from `logos/json.svg`
- `yaml.svg` from `logos/yaml.svg`
- `markdown.svg` from `logos/markdown.svg`

`archive.svg` is an original, text-free archive symbol created for the ACORN documentation; the SVG Logos collection does not include a BagIt or ZIP mark.
