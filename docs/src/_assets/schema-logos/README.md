# Schema logo sources

The schema tree uses these unmodified vector assets:

- `rust.svg`, `python.svg`, `typescript-icon.svg`, `pytorch.svg`, `docker-icon.svg`, `webassembly.svg`, `github.svg`, and `gitlab.svg` from the [SVG Logos collection](https://github.com/gilbarbara/logos), distributed under CC0-1.0. Brand marks remain the property of their respective owners.
- `ror.svg` from the [official ROR logo repository](https://github.com/ror-community/ror-logos), distributed under CC BY-ND 4.0 and used without modification.
- `doi.svg` by the DOI Foundation from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:DOI_logo.svg), used without modification. The simple text logo is public domain and may be subject to trademark restrictions.
- `orcid.svg` by ORCID from the [ORCID iD icon graphics](https://orcid.figshare.com/articles/figure/ORCID_iD_icon_graphics/5008697), distributed under CC0 and used according to the [ORCID display guidelines](https://info.orcid.org/documentation/integration-guide/orcid-id-display-guidelines/).

The ACORN, JSON, YAML, and Markdown marks are reused from existing documentation assets; their provenance remains documented alongside those assets.

The `metadata.svg` structured-record mark was created for the ACORN documentation.
