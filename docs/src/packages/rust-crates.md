# Rust Crates

The Rust workspace separates portable data types and analysis from native services and application interfaces. Start with [`acorn-schema`](acorn-schema.md) for research metadata and validation, [`acorn-analysis`](acorn-analysis.md) for portable findings, or [`acorn-lib`](acorn-lib.md) for native workflows.

Smaller integrations can use [`acorn-diff`](acorn-diff.md), [`acorn-cmd`](acorn-cmd.md), [`acorn-host`](acorn-host.md), or [`acorn-service`](acorn-service.md). The [Protobuf and gRPC](grpc.md) guide covers `acorn-server`; [WebAssembly development](acorn-web.md) covers `acorn-wasm`.
