# ISO 639-3 validation data

`iso-639-3.txt` contains the sorted `Id` column from the ISO 639-3 code table published by [SIL Global, the Language Coding Agency](https://iso639-3.sil.org/). It is incorporated solely for offline language-code validation; ACORN does not expose a code-table download API.

Source: [ISO 639-3 code table](https://iso639-3.sil.org/sites/iso639-3/files/downloads/iso-639-3.tab), downloaded 2026-11-12 (2026-10-15 release).

Source SHA-256: `07ce5fed94472312bdd1a4bd7f297c83e7cd4ac4ff335dfbed0824a270f482ed`.

Use is governed by the [ISO 639-3 Code Tables Terms of Use](https://iso639-3.sil.org/code_tables/download_tables#termsofuse). Code identifiers are unmodified. To refresh, download the source, extract the `Id` column without its header, sort it, and update this notice. Do not add private or invented codes.
