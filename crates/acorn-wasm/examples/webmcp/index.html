ACORN browser tools

Validate and assess metadata, work with research identifiers, compare content, run typed crosswalks, and check prose locally with ACORN WebAssembly. Manual controls remain available when WebMCP is unsupported.

A browser agent may send tool inputs and outputs to its configured model provider. ACORN itself performs these operations locally and does not add network, filesystem, storage, or process access.
