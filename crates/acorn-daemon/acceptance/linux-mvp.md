Native execution exposed three defects before the final report check. Read-access events from `acorn check` repeatedly requeued its watched input; the scheduler now accepts only create, modify, and remove events. Fourteen focused scheduler tests passed on macOS and Linux, including a read-versus-write watcher case. Managed Vale 3.9.4 rejected the downloaded proselint `LexicalIllusions` regex even when that rule was disabled in `.vale.ini`. During acceptance, a temporary source workaround removed that cached rule after managed sync; with the bad file restored before the test, runs 99/101/103 succeeded. Hunk review removed that workaround and the associated default rule change, so those successful check runs do not validate the current managed Vale path. The check runner's stdout also contained Vale sync progress before its JSON; a fixed global `--quiet` argument resolved this, with nine focused runner tests passing on macOS and Linux and native reports 125/127/130 passing `jq`. A Linux installer review also added literal dollar-path escaping and malformed-token rejection. Focused CLI tests (3), Linux installer tests (3), and package Clippy with warnings denied passed. These observations cover source-built local service behavior; signed bundles, SSH installation, and release upgrade acceptance belong to later phases.
