# Fictional research bucket

Synthetic examples for the ACORN browser. All project titles, people, organizations and images are invented.

The bucket contains 14 fictional project folders. Eleven have JSON activity records for the Portfolio; seven of those have multiple illustrations and one deliberately has none. Three other folders demonstrate YAML or Markdown records. The DOI, ORCID and ROR values are illustrative identifiers and are not evidence of registered people, organizations or publications.
