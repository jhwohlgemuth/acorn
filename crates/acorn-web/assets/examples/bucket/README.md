# Fictional research bucket

Synthetic examples for the ACORN browser. All project titles, people and images are invented. Each project uses a different registered organization and ROR ID solely to exercise validation; the projects and people are fictional.

The bucket contains 14 fictional project folders. Eleven have JSON activity records for the Portfolio; seven of those have multiple illustrations and one deliberately has none. Three other folders demonstrate YAML or Markdown records. The DOI and ORCID values are illustrative identifiers and are not evidence of registered people or publications.
