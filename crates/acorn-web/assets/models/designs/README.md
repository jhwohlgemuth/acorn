# Original design references

The four concept sheets, original brief and generation prompts were preserved from the initial design pass. They are reference art, not renders of the delivered GLBs. Current models, ORNL colors, inventories and actual renders are documented in the [model guide](../README.md). The original brief's statement that GLBs do not yet exist is historical and superseded.

All Wonder models have been removed from the active library. The Wonders concept sheet is retained only as historical reference art.
