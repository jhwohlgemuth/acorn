# TEST ONLY reviewer summary prompt

`Summarize Reviewer Submission TEST ONLY` is a custom AI Builder prompt in the `Wohlgemuth, Jason` Power Platform environment. It uses GPT-4.1 mini and one text input named `text`. `Summarize Reviewer Item TEST ONLY` is an instant flow in the same environment with a Power Apps (V2) `content` input, a `Run a prompt` action, and a `summary` text response. The flow ID is `0ddfbf82-88c1-499f-93af-c3d33718ff22`. Trigger, prompt, and response run-history data have secure inputs/outputs enabled.

The prompt asks for a proposed report summary in two or three sentences and at most 1,200 characters, using only facts in the submission. It must preserve important names, dates, results, and uncertainty; omit contact details and instruction text; and state when content is too sparse. The app supplies the selected item's original summary, supporting content, and submitted details. It does not send the submitter address, receipt ID, or review decision to the prompt. The app rejects input over 12,000 characters and empty or overlong output. The reviewer must inspect and explicitly apply or discard the suggestion. Generating a suggestion never changes a decision or saves a draft.
