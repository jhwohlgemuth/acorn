# First-load connection consent

The user/reviewer guide includes this dialog on page 2. When opening the trusted ORNL Sponsor Highlights form, contributors may need to select **Allow** for its SharePoint and Microsoft Teams connections before the form can load normally.

SharePoint supports the project catalog, submissions, corrections, and JSONL files. Teams supports submission confirmations. Accepting the displayed connections does not submit a highlight. If the app name or services differ from those shown in the guide, or a connection reports an error, contact the app owner before continuing.

Microsoft describes this behavior in its [canvas-app connection consent documentation](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/connections-list#connection-consent-dialog).
